# 自訂 3D 角色（選用）

演練前可選「女生／男生」。程式會在這個資料夾依序找 **VRM** 模型，找到第一個就用：

| 性別 | 尋找順序 |
|---|---|
| 女生 | `female_<性格>.vrm` → `female.vrm` → `default.vrm` → 內建卡通女生 |
| 男生 | `male_<性格>.vrm` → `male.vrm` → 內建卡通男生 |

- `<性格>` 為：強勢直率、敏感玻璃心、情緒勒索、開門見山、一般友善。例如 `male_強勢直率.vrm`。
- `default.vrm` 視為**女生**模型，選男生時不會使用它。
- 放好後在瀏覽器按 Ctrl+F5 重新整理即可，不需重啟後端。

## 怎麼取得 .vrm
- 用免費的 VRoid Studio 自己建立角色，匯出成 VRM。
- 或從 VRoid Hub、Booth 等平台下載。**請先確認授權允許你的用途**（個人／商用、能否修改、是否要標示作者）。

## 建議規格（手機瀏覽器才順暢）
- 檔案約 15 MB 以下，貼圖不超過 2048 像素，面數幾萬以內。
- 需要含表情（happy / angry / sad / surprised）、`aa` 嘴型與 `blink`，VRoid 匯出的模型預設都有。
